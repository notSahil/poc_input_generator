03

⚙️ The Reconciliation Engine & 5 Standard Output Files Audit Boundary

Strict mathematical separation guarantees that bad rows never touch production

1. final_input_file.csv

Valid rows with Target Columns + Primary Key. Ready for instant upload.

2. field_level_changes.csv

Granular audit log of every detected change: Old_Value vs New_Value.

3. invalid_primary_key.csv

Quarantined exact copy of rows where Primary Key was null or blank.

4. duplicate_primary_keys.csv

Quarantined exact copy of rows where Primary Key appeared multiple times.

5. run_summary.txt

Executive mathematical metrics: processed, modified, errors & time.

Supplementary Files: audit.log (system traces) • rollback_file.csv (1-click undo) • run_summary.json (telemetry) Saved in runs/<timestamp>/
